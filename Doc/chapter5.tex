\subsection{ข้อจำกัดด้านการทำงาน}
\subsubsection{ความแม่นยำของข้อมูลการวิ่งขึ้นอยู่กับคุณภาพสัญญาณ GPS และเซนเซอร์ของอุปกรณ์}
\subsubsection{การปรับแผนการฝึกอาศัยข้อมูลที่ผู้ใช้บันทึกและประเมินตนเอง จึงอาจแตกต่างตามความถูกต้องของข้อมูลที่ผู้ใช้ให้}
\subsubsection{ผลการทดสอบยังไม่ครอบคลุมทุกเส้นทาง ได้แก่ Google sign-in การเชิญและตอบรับเพื่อนระหว่างสองบัญชี สิทธิ์เข้าถึงข้อมูลของผู้ใช้อื่น การปรับสิทธิ์สมาชิกชมรม การอัปโหลด Avatar การซื้อสินค้าเมื่อเหรียญไม่พอ และตารางจัดอันดับ}
\subsubsection{ระบบยังไม่ได้พัฒนาการเชื่อมต่อและนำเข้าข้อมูลการวิ่งจาก Strava ผู้ใช้จึงบันทึกการวิ่งผ่านแอปพลิเคชันของระบบเท่านั้น}
\subsubsection{การปรับแผนด้วย Machine Learning ยังไม่ได้พัฒนา ไม่ใช่ฟังก์ชันที่ทดสอบแล้ว}

\subsection{ข้อจำกัดด้านฮาร์ดแวร์และซอฟต์แวร์}
\subsubsection{แอปพลิเคชันต้นแบบมุ่งใช้งานบนระบบปฏิบัติการ Android}
\subsubsection{ประสิทธิภาพในการติดตามการวิ่งอาจแตกต่างกันตามรุ่นและประสิทธิภาพของสมาร์ตโฟน}
\subsubsection{Line Coverage ของชุดทดสอบไม่เท่ากันทุกโมดูล เช่น clubService.js ร้อยละ 36.33 และ runningService.js ร้อยละ 65.38}

\subsection{ข้อจำกัดด้านการประเมินกับผู้ใช้}

การทดลองหนึ่งรอบกับกลุ่มที่คัดเลือกแบบเจาะจงสะท้อนปัญหาและความพึงพอใจครั้งแรกเฉพาะผู้เข้าร่วม ยังไม่ครอบคลุมการกลับมาใช้ การเปลี่ยนพฤติกรรม หรือผลต่อการบาดเจ็บ รอบนี้เก็บได้จริง 3 คนจากเป้าหมายประมาณ 5 คน มีผู้เคยใช้แอป 1 คน และไม่มีข้อมูลเวลา/การช่วยเหลือรายภารกิจ จึงใช้ผลเพื่อค้นหาประเด็นปรับปรุงเบื้องต้น ไม่ยืนยันคะแนนแทนประชากร \cite{budiu2021five}

\subsection{การทดสอบและการประกันคุณภาพ}

\begin{enumerate}[label=\arabic*)]
    \item เพิ่มกรณีทดสอบเชิงพฤติกรรมให้โมดูลที่ Coverage ต่ำ เช่น clubService.js และ runningService.js
    \item ทดสอบ API ด้วยสองบัญชีขึ้นไป ได้แก่ การเชิญและตอบรับเพื่อน การเข้าร่วมและการจัดการสมาชิกชมรม และสิทธิ์เข้าถึงข้อมูลของผู้ใช้อื่น
    \item ทดสอบ Google sign-in การอัปโหลด Avatar และกรณีซื้อสินค้าเมื่อเหรียญไม่พอบนสภาพแวดล้อมทดสอบจริง
    \item รัน Postman collection ทั้งชุดซ้ำบน commit ล่าสุด และทดสอบเส้นทางที่ไม่มีใน API หลังปรับลำดับ middleware
\end{enumerate}

\subsection{แนวทางการวิจัยต่อยอด}

การประเมินแรงจูงใจระยะยาวที่ระบุในตารางที่~\ref{tab:remaining-work} ควรเก็บค่าฐานก่อนใช้งานและติดตามข้อมูลรายสัปดาห์อย่างต่อเนื่อง โดยกำหนดระยะเวลาติดตามและขนาดตัวอย่างให้เหมาะกับคำถามวิจัย เพื่อศึกษาการเปลี่ยนแปลงแรงจูงใจ ความสม่ำเสมอ การกลับมาใช้งาน และการทำตามคำแนะนำ ทั้งนี้ การติดตามเพียง 2--4 สัปดาห์อาจใช้ประเมินแนวโน้มเบื้องต้น แต่ยังไม่เพียงพอสำหรับยืนยันผลระยะยาว ส่วนความแม่นยำและความปลอดภัยของการปรับภาระฝึกควรประเมินแยกต่างหาก ข้อเสนอเหล่านี้เป็นแนวทางประเมินในอนาคต ไม่ใช่ผลการทดลองรอบปัจจุบัน
